3作品の設計・検証レポート

PHYSICA v1.1を保全し、同じ基本ルールと画面構成でCHEMICA・BIOTICAを追加した実装版です。カードの数値は学習内容を想起するための抽象表現であり、現実の法則や生命現象の数値シミュレーションではありません。

重要：全15デッキの公平性を達成した完成版ではありません。

新作の能力調整とクロス対戦は実装・検証済みですが、既存PHYSICAのカード性能を維持したため、同一CPUモデルでは波動が強く電磁気が弱い偏りが残ります。「既存性能を維持する」と「全15デッキを均衡させる」の両方を、この版で達成したとは扱いません。以下の数値は固定CPUと標準構築に限る測定であり、人間対戦の勝率や任意の構築の公平性を保証しません。

PHYSICA高校物理 / 5デッキ / 117カード
CHEMICA高校化学 / 5デッキ / 75カード
BIOTICA高校生物 / 5デッキ / 75カード

1. 維持した仕様と拡張箇所

初期コアHP24、初手5枚、30枚構築・同名3枚まで、実験体3体、手札上限8枚、登場ターン攻撃不可、ターンごとのエネルギー回復と考察＋1、3段階CPU、デッキ編集・図鑑・チュートリアル・BGM／効果音・考察提案設定・PWA構造を継承しました。PHYSICAの既存117枚のカードデータと5つの標準デッキは固定した比較データと一致します。

追加は150枚の学習カードと対応する3択問題、10分野、12種類の追加能力系統、教科別ブランド・保存領域・PWAアイコン、3作品共通の通信プロトコルです。共通のルール判定・能力・CPU・通信・UIモジュールを再利用し、物理データは独立したファイルに保持しています。

2. CHEMICA：5分野の学習・戦略設計

構造・状態 — CHEMICA / 15カード

学習範囲
原子・周期表・結合、物質量・濃度、精製、気体・結晶、溶液・状態平衡
コンセプト
単位となる実験体を結合で補強する安定型
戦略的特徴
結合は他の仲間がいると強化量が増加。防壁と手札補充で場を保つ。
得意な状況
小型の仲間を先に出せて、中盤に2体を維持できる場面。
苦手な状況
味方がいない序盤や、全体攻撃で場を一掃される展開。

反応・エネルギー — CHEMICA / 15カード

学習範囲
反応式・反応量、エンタルピー、ヘスの法則、酸化還元、電池・電気分解・滴定
コンセプト
蓄積した防壁を使い、反応出力へ変換する放電型
戦略的特徴
防壁1を消費できれば放電ダメージが1増える。直接攻撃と継続圧力を使い分け。
得意な状況
準備した防壁が残り、倒したい低HPの敵がいる場面。
苦手な状況
防壁を削られ続ける展開や、単体除去だけでは足りない横展開。

平衡・速度 — CHEMICA / 15カード

学習範囲
速度式・触媒・化学平衡、酸塩基・中和、電離平衡、緩衝液・溶解度積
コンセプト
状態差を読み、資源または防御を得る応答型
戦略的特徴
平衡応答は手札が少なければドロー、多ければ防壁。中和は熱傷の蓄積に対応。
得意な状況
相手の手札が多い状況や、熱傷を軸に攻められる場面。
苦手な状況
手札差がなく、防御を貫通する高火力で短期決着を狙われる場面。

無機化学 — CHEMICA / 15カード

学習範囲
典型・遷移元素、錯体、金属イオン分析、無機工業、材料・元素確認
コンセプト
相手の主力を沈殿で鈍らせる単体制御型
戦略的特徴
沈殿は相手最大攻撃の実験体を弱体化。単体ダメージを合わせて交換を有利に。
得意な状況
相手が少数の高攻撃実験体へ強化を集中する場面。
苦手な状況
敵がいない状態からのコア直接打点や、手数の多い再展開。

有機・高分子 — CHEMICA / 15カード

学習範囲
官能基・異性体、炭化水素、酸化・縮合、芳香族、生体分子、合成・天然高分子
コンセプト
単量体に見立てた仲間をつなぐ連鎖型
戦略的特徴
重合は最もHPが高い味方を強化し、味方2体以上なら1枚引く。場の維持と連鎖を両立。
得意な状況
高耐久の核となる実験体を残して、もう1体を添えられる場面。
苦手な状況
核となる実験体への集中攻撃や、育成前の速攻。

3. BIOTICA：5分野の学習・戦略設計

細胞・代謝 — BIOTICA / 15カード

学習範囲
細胞小器官・膜輸送、タンパク質・酵素、ATP、呼吸・発酵・光合成・同化
コンセプト
資源循環と修復で行動をつなぐ代謝型
戦略的特徴
代謝でエネルギーを回復し、2体以上なら傷ついた味方を修復。場と手札の消費に注意。
得意な状況
使えるカードが手札にあり、盤面に複数体が生存している場面。
苦手な状況
手札切れ、全体除去、資源を得ても使う先がない場面。

遺伝・発生 — BIOTICA / 15カード

学習範囲
DNA複製・発現・調節、細胞周期・遺伝、生殖・発生・分化、遺伝子技術
コンセプト
一度失った情報を回収する再構築型
戦略的特徴
転写再生は捨て札から最低コストの実験体1枚を手札へ。同名の回収は1試合1回までで、再展開には通常通りコストが必要。
得意な状況
小型実験体を交換した後、低コストで場を作り直す長期戦。
苦手な状況
捨て札がない初動や、高コスト回収だけになってテンポを失う場面。

恒常性・応答 — BIOTICA / 15カード

学習範囲
体液・内分泌・自律神経、腎臓、免疫、神経・感覚・運動・行動、植物応答
コンセプト
損傷や変動に応じて回復を強める応答型
戦略的特徴
恒常性応答は熱傷を解除し、HP12以下なら回復が追加。拘束で1ターンを稼ぐ。
得意な状況
小さな継続ダメージや熱傷を受け、回復で逆転できる場面。
苦手な状況
回復前にHPを0にする集中打点や、相手の大量展開。

生態 — BIOTICA / 15カード

学習範囲
個体群・種間関係、食物網・生産、物質循環、植生・遷移、バイオーム・保全
コンセプト
単独より複数で便益を得る共生型
戦略的特徴
共生は味方が2体以上なら防壁量が増え、負傷した味方を修復。横展開を保つ。
得意な状況
場に2〜3体を残し、小さな打点を防壁で受けられる場面。
苦手な状況
全体ダメージや、味方を1体以下に抑えられる展開。

進化・系統 — BIOTICA / 15カード

学習範囲
生命・細胞の起源、自然選択・集団遺伝、種分化・分子進化、分類・系統・人類
コンセプト
相手の盤面優位を条件に差を縮める適応型
戦略的特徴
適応は相手の最大攻撃力が自陣以上なら強化が増える。反応するための自分の実験体が必要。
得意な状況
相手が先に強い実験体を出し、こちらにも強化先が生き残る場面。
苦手な状況
対象になる味方がいない状態や、相手がコア打点だけで戦う場面。

4. バランス測定と調整

最終測定は15デッキの全105組合せ×20試合＝2,100試合。同じseedを先後交代で用い、各組合せで先攻・後攻を10試合ずつ担当しています。各デッキの全体勝率は他の14デッキとの280試合、作品内勝率は同じ作品の他4デッキとの80試合に基づきます。ミラーマッチや編集済みデッキは含みません。NORMAL CPUの同一評価関数・考察正答率75%の擬似乱数モデルです。

初回と3回の調整後測定を合わせて8,400試合、元PHYSICAの基準測定400試合を実施。回収が延々と続く遺伝デッキを「同名回収は1試合1回」に制限し、追加分野だけの攻撃力・HPを調整しました。元の物理カード数値は変更していません。測定中に得た相性に合わせた調整なので、別seed・別CPU・実際の人間対戦による追試が必要です。

未完了の調整

PHYSICAの性能を変えない条件では、特に波動・電磁気を含む全体均衡に未達です。リリース前には、旧版を残した上で別の「シリーズ調整版」を明示的に設けるか、既存カード／既定デッキの変更を承認して再調整する必要があります。この版では無断で物理の数値を変える選択はしていません。

5. オンライン連携と確認範囲

3作品とも共通のルーム名前空間とバージョン付きハンドシェイクを使用します。ホストが両者のカードを判定できる共通レジストリを持ち、参加者は起動した作品のデッキを送ります。自分の教科に対応した考察問題を出題します。相手の手札と山札順序はゲストへ送らない従来方式を維持しています。

3作品連携には、PHYSICAも同梱のv1.2に更新してください。旧v1.1のルームコードとは接続できません。各作品を別々のWebサイトに配置する場合も、同じv1.2ファイルを使ってください。

PHYSICA↔CHEMICA、CHEMICA↔BIOTICA、BIOTICA↔PHYSICAの3通りで、別オリジンのブラウザ間接続、双方向のターン・考察同期、切断通知を確認しました。3作品それぞれのチュートリアル完走、スマホ幅320〜430px、マニフェスト、CPU操作、オフライン再起動も確認しています。

確認はChromiumの端末エミュレーションと同一検証環境内のブラウザ間です。iPhone／Android実機や異なる携帯NAT回線での成功保証はありません。公開PeerJSサーバーを使用する試作方式で、回線によって接続できない場合があります。再接続、ホスト改ざん耐性、本番用の専用シグナリング／TURN基盤は未対応です。

6. 公開・起動・ソース構造

公開用ZIPを解凍して、index.html・physica・chemica・bioticaを含むフォルダの中身をHTTPSの静的ホスティングへ配置します。入口ページから各作品へ移動できます。ホーム画面には、入口でなく各作品のページを開いてから追加してください。アイコン、マニフェスト、オフラインキャッシュは作品ごとに独立しています。個別配置する場合は各作品のフォルダ内容だけでも動作します。

ダウンロードした単独HTMLは主にPCでの試遊用です。PWAとしてのホーム画面追加と安定したスマホ運用には公開URLが必要です。BGMはブラウザ内の軽量シンセで、最初のタップ後に始まります。各作品のデッキ・設定・記録はブラウザ内の別キーで保存します。公開URLやブラウザを変更すると同じ保存記録は引き継がれない場合があります。

npm ci
npm run dev              # PHYSICA
npm run dev:chemica      # CHEMICA
npm run dev:biotica      # BIOTICA
npm run build            # dist/ に3作品を生成
npm test                 # カード・ルール・回収制限など
npm run test:balance     # 検証用の総当たり
npm run preview          # ビルドをローカル確認

開発にはNode.js 22.12以上を推奨。ブラウザテストにはPlaywrightのChromiumをインストールし、distを4180番で配信した上で npm run test:e2e を実行します。verification/ の集計は同梱コードで取得した検証時点の結果です。コードやカードを変更したら、再測定してください。

7. 教材の範囲・出典

学習指導要領と対応する公開シラバスの主要単元をもとに、独自の学習文と選択肢を作成しています。化学・生物はそれぞれ75カードで主要概念を扱い、全用語・全反応・全実験問題を完全に網羅するものではありません。文中の概念式と、厳密な計算式・近似式は成立条件を確認して使ってください。

  • 文部科学省｜高等学校学習指導要領解説 理科編・理数編
  • PeerJS｜通信ライブラリの仕様・制限
  • JASSO｜化学基礎・化学に対応する出題範囲
  • JASSO｜生物基礎・生物に対応する出題範囲
